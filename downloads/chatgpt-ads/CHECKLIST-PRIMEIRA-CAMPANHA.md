# Checklist da primeira campanha no ChatGPT Ads

## Conta

- [ ] Ads Manager disponível para o anunciante.
- [ ] Marca e favicon corretos.
- [ ] Verificação concluída.
- [ ] Cobrança configurada.
- [ ] Pessoas e permissões revisadas.

## Campanha

- [ ] Objetivo ligado ao resultado do negócio.
- [ ] Evento de conversão confirmado, quando aplicável.
- [ ] Orçamento decidido pelo dono.
- [ ] Datas corretas.
- [ ] Localizações disponíveis e revisadas.

## Grupos

- [ ] Um tema ou situação por grupo.
- [ ] Pistas de contexto claras e seguras.
- [ ] Nenhum atributo sensível explorado.

## Anúncios

- [ ] Título simples e específico.
- [ ] Benefício prático claro.
- [ ] Imagem coerente.
- [ ] Página de destino específica.
- [ ] URL válida e acessível.
- [ ] UTMs configuradas.

## Medição

- [ ] Evento testado.
- [ ] Pixel e ou API configurados conforme o plano.
- [ ] Página de conversão correta.
- [ ] Primeira data de revisão marcada.

## Aprovação

- [ ] Resumo completo apresentado ao dono.
- [ ] Aprovação explícita recebida antes do lançamento.
